# English for Kids

Интерактивный тренажёр английского языка для учеников второго класса. Здесь можно заниматься грамматикой, чтением и лексикой, слушать произношение и следить за своими успехами. Во время занятий помогает обезьянка Тоби.

## Главная страница

На главной странице можно выбрать один из трёх учебных разделов или открыть свой прогресс.

![Главная страница](screenshots/home.webp)

## Выбор темы

В каждом разделе собраны темы с различными упражнениями по ним.

![Выбор темы](screenshots/topics.webp)

## Упражнение

Задания помогают закрепить правила и новые слова. Нужно выбрать правильный ответ или вписать слово.

![Упражнение](screenshots/exercise.webp)

## Упражнение с картинкой

Некоторые задания используют изображения.

![Упражнение с картинкой](screenshots/image-task.webp)

## Мой прогресс

В этом разделе ученик может посмотреть, сколько заданий выполнено по каждой теме и сколько ответов было правильными или неправильными.

![Мой прогресс](screenshots/progress.webp)

## Сохранение прогресса

Имя ученика и результаты занятий сохраняются в браузере на том устройстве, где проходят занятия. На другом устройстве эти данные не появятся. При очистке данных браузера сохранённые результаты могут удалиться.
