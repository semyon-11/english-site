# English for Kids

Это небольшой сайт для тренировки английского языка во 2 классе. Здесь можно выбрать раздел, выполнить задания, послушать английские слова и посмотреть свои результаты.

## Что есть на сайте

- Грамматика, чтение и лексика.
- Задания с выбором ответа, вводом слов, картинками, сопоставлением и аудированием.
- Вопросы перемешиваются и не повторяются, пока не закончится текущий круг.
- Тоби помогает во время занятий.
- Результаты сохраняются отдельно для каждого браузера.

## Как запустить сайт

Скачайте проект:

```bash
git clone https://github.com/semyon-11/english-site.git
cd english-site
```

Запустите простой локальный сервер:

```bash
python -m http.server 8000
```

Откройте в браузере адрес <http://localhost:8000>.

Для публикации используйте GitHub Pages: в настройках репозитория выберите ветку `main` и папку `/(root)`.

## Проверка проекта

Для запуска тестов нужен Node.js версии 20 или новее. В папке проекта выполните:

```bash
npm test
```

Сам сайт не требует Node.js, установки библиотек или сборки.

## Где находятся файлы

- `index.html` — страница сайта.
- `css/` — оформление и расположение элементов.
- `js/content.js` — темы и учебные задания.
- `js/exercises.js` — показ заданий и проверка ответов.
- `js/exercise-generators.js` — создание отдельных видов заданий.
- `js/mascot.js` — поведение Тоби.
- `js/progress.js` — сохранение и показ результатов.
- `js/speech.js` — озвучивание слов.
- `images/` — картинки для заданий и персонаж сайта.
- `tests/` — автоматические проверки.

## Результаты и озвучивание

Имя ученика и результаты хранятся в браузере. Они не переносятся на другое устройство. Если очистить данные браузера, сохранённые результаты тоже могут удалиться.

Озвучивание зависит от браузера и голосов, установленных на устройстве. Поэтому произношение может немного отличаться.
