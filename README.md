# English for Kids

Интерактивный тренажёр по английскому языку для учеников начальной школы. В нём есть короткие задания по грамматике, чтению и лексике, картинки, озвучивание слов и сохранение результатов.

## Возможности

- 17 тем в трёх разделах: грамматика, чтение и лексика.
- Семь форматов заданий: выбор ответа, ввод слова, сопоставление, задания по картинкам, эмоции и аудирование.
- Случайный порядок вопросов без повторов до конца текущего цикла.
- Проверка ответа сразу после выполнения.
- Страница с результатами по темам.
- Озвучивание английских слов и букв средствами браузера.
- Адаптивная вёрстка.
- Для запуска сайта не нужны зависимости и сборка.

## Запуск

Нужен современный браузер.

Скачайте проект и перейдите в его папку:

```bash
git clone https://github.com/semyon-11/english-site.git
cd english-site
```

Запустите локальный сервер:

```bash
python -m http.server 8000
```

Откройте <http://localhost:8000>.

Для публикации на GitHub Pages откройте **Settings → Pages → Deploy from a branch**, затем выберите ветку `main` и папку `/(root)`.

## Учебные данные

Темы и задания находятся в `js/content.js`. При добавлении вопроса укажи формат задания и необходимые для него поля. Например:

```js
{
    type: 'fillBlank',
    instruction: 'Напишите слово на английском',
    questions: [
        { q: 'солнечно — ___', a: ['sunny'] },
        { q: 'дождливо — ___', a: ['rainy'] }
    ]
}
```

После изменения данных запусти проверки:

```bash
npm test
```

Для тестов нужен Node.js 20 или новее. Сам сайт по-прежнему работает без Node.js и сторонних библиотек.

## Прогресс и ограничения

Имя ученика и результаты хранятся в `localStorage` текущего браузера. Они не синхронизируются между устройствами. Если браузер запрещает локальное хранилище, задания остаются доступны, но результаты не сохраняются.

Озвучивание зависит от поддержки Web Speech API и установленных в системе английских голосов. Голоса и произношение могут отличаться в разных браузерах и операционных системах.
