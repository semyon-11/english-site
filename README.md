# English for Kids

Интерактивный тренажёр английского языка для учеников второго класса. Здесь можно заниматься грамматикой, чтением и новыми словами, слушать произношение и следить за своими успехами. Во время занятий помогает Тоби.

## Разделы

- **Грамматика** — простые упражнения по правилам английского языка.
- **Чтение** — знакомство с буквами, звуками и словами.
- **Лексика** — изучение новых слов по темам.

## Задания

На сайте есть задания с выбором ответа, вводом слов, картинками, сопоставлением и аудированием. Вопросы перемешиваются, чтобы занятия не повторялись в одном и том же порядке.

## Тоби и звуки

Тоби сопровождает ученика на разных экранах, поддерживает после ошибок и радуется правильным ответам. Нажатия и ответы сопровождаются короткими звуковыми сигналами. Их громкость также зависит от настроек звука на устройстве.

## Мой прогресс

Имя ученика и результаты занятий сохраняются в браузере на том устройстве, где проходят занятия. На другом устройстве эти данные не появятся. При очистке данных браузера сохранённые результаты могут удалиться.

Файлы сайта сгруппированы по назначению: оформление находится в папке `css`, сценарии — в папке `scripts`, а изображения — в папке `images`.
